# 004 ログインとアカウント

- 状態：完了
- 依存：001

## 👤 ユーザーが確認するところ

### 何のための機能か
家族だけがクラウドの在庫を見たり変えたりできるようにします。一方で、ネットが切れたときやログインの有効期限が切れたときでも、この端末に保存済みの在庫は見られるようにします。

### できるようになること
- 大人2人それぞれのアカウント（メールアドレス＋パスワード）でログインする。家族で1つの ID を使い回さない。
- 誰でも登録できる「新規登録」画面は作らない。アカウントは、決まった手順でだけ追加できる（あとから子どもの分を足すこともできる）。
- 一度ログインしてデータを保存した端末では、**ネットがないときや、ログインの有効期限が切れたときでも、保存済みの在庫を見られる**（見るだけ。編集はできない）。
- ネットにつながっていてログインの有効期限が切れている場合は、在庫を見せたまま「編集するには再ログインが必要」と表示する。
- ログアウトするときは、この端末に保存した在庫も一緒に消すかどうかを選べる（消す場合は確認あり。008）。

### 使い方の流れ
1. 初回だけ、ネットにつながった状態でアプリを開き、メールアドレスとパスワードでログインする。
2. ログインすると在庫がこの端末に保存される（005）。
3. 以降はアプリを開くだけ。ログインし直す必要があるのは、長く使わなかったときなどにクラウド側のログインが切れた場合だけ。

### 知っておいてほしいこと
- **端末を操作できる人には、保存済みの在庫が見える作り**です（ネットがなくても見られるようにするため）。端末の画面ロックをかけておいてください。住所や健康情報などは在庫に書かないでください。

### やらないこと
- メールのリンクやワンタイムコードでのログイン、Google などでのログイン。
- パスワードを忘れたときのメール再設定（Supabase 標準のメール送信は制限が厳しいため）。忘れたときは、アカウント追加と同じ手順でパスワードを設定し直す。
- 家族内の権限の分け方。将来の拡張。

### チャットで決めたこと
| 決めたこと | 理由 |
|---|---|
| アカウントは大人2人分だけ作る。子どもは親の端末で見る | 編集するのは大人。あとから追加できる |
| ログインはメールアドレス＋パスワード | アプリの中だけで完結する。家族は全員 Android なので iPhone 特有の制約は考えない |

- 実装前に準備するもの：なし
- 完成後に手で確認するもの：なし
- 公開の準備（009）で、大人2人のパスワードを決めて入力してもらいます（パスワードは本人が決めるもので、Claude が決めたり入力したりできないため）。

### 設計方針
- `@supabase/supabase-js` の auth（`persistSession: true`、`autoRefreshToken: true`）。
- **閲覧できるかどうかの判断を、認証状態と切り離す。** 起動時はまず IndexedDB のスナップショットを読む（005）。ローカル側の「最後にログインしたユーザー」は `localMeta`（IndexedDB）に `{userId, householdId}` で持ち、これを使ってスナップショットを特定する。セッションの検証はその後、オンラインのときだけ行う。
- ログイン状態は `unknown | signedIn | needsReauth | signedOut`（オフラインで確かめられないときは前の値のまま）。編集可否 = オンライン かつ signedIn かつ 端末に保存済み かつ 同期中でない。
- サインアップ無効：`supabase/config.toml` の `[auth] enable_signup = false` を本番へ反映（009）。
- `scripts/member-add.ts`：`--email` と `--household`（省略時は唯一の家庭）を受け取り、パスワードはTTYの非表示入力（2回）。service_role で `auth.admin.createUser({email_confirm: true})` → `household_members` へ追加。既存ユーザーならパスワードの再設定だけ行う（`--reset-password`）。

### 検討した案と不採用の理由
| 案 | 採用 | 理由 |
|---|---|---|
| オフライン時もトークン期限で閲覧をブロック | 不採用 | BRIEF 6.3 |
| 招待メール | 不採用 | 標準メール送信の制限が厳しく、パスワード設定の手間はコマンドでも同じ |
