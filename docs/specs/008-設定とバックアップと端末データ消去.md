# 008 設定とバックアップと端末データ消去

- 状態：合意済み
- 依存：005

## 👤 ユーザーが確認するところ

### 何のための機能か
端末の保存データがブラウザの都合で消えたときに備えて、在庫を手元のファイルに書き出せるようにします。また、端末を手放すときなどに、この端末のデータを消せるようにします。

### できるようになること
- 設定画面に、次の情報を表示する。
  - ログイン中のメールアドレス
  - この端末に保存済みか、最終同期日時、保存されている明細数・保管場所数
  - 永続保存の申請結果（許可／不許可／未対応）と、その意味の説明
  - アプリの版
- 「今すぐ同期」ボタン（オンラインのとき）。
- **バックアップの書き出し**：
  - JSON（保管場所と在庫をすべて含む。あとで別の仕組みに取り込むための形式）
  - CSV（表計算ソフトで開ける一覧。文字化けしないよう Excel 向けの形式）
  - 書き出しは**端末に保存済みのデータから作る**ので、オフラインでもできる。ファイル名に書き出した日時と最終同期日時を入れる。
- **ログアウト**：2つから選ぶ。
  - ログアウトだけ（この端末の在庫は残し、オフラインで見られるまま）
  - ログアウトして、この端末の在庫も消す（「消すとネットにつながるまで在庫を見られなくなります」と確認してから消す）
- 「データが消える場合」の説明を表示する：ブラウザのデータ消去、アプリの削除、機種変更、長期間使わないとき、端末の空き容量不足など。対策として、ときどきバックアップを書き出すこと。

### 使い方の流れ
1. 設定タブを開く。
2. 「JSON で書き出す」または「CSV で書き出す」を押すと、端末にファイルが保存される。
3. 端末を手放すときは「ログアウトして、この端末の在庫も消す」。

### やらないこと
- バックアップからの復元（取り込み）。BRIEF でも必須ではない。
- 印刷用の一覧・PDF 出力。将来の拡張。

## 🤖 実装メモ（Claude 用。ユーザーは読まなくてよい）

### 受け入れ条件
- [ ] AC1：JSON 書き出しが `{format: "sonaelog-export", version: 1, exported_at, snapshot_captured_at, household_id, locations, lots}` で、ローカルのスナップショットと明細数が一致する（自動テスト）
- [ ] AC2：CSV が UTF-8 BOM 付き・CRLF、カンマ・改行・ダブルクォートを含む値が正しくエスケープされ、期限は記録どおりの文字列（`2027-08` のまま）（自動テスト）
- [ ] AC3：オフラインでも書き出しができる（自動テスト：Playwright の download イベント）
- [ ] AC4：「ログアウトだけ」ではスナップショットが残り、オフラインで閲覧できる（自動テスト）
- [ ] AC5：「ログアウトして消す」では確認ダイアログを経て、IndexedDB の当該スナップショットと `lastUser` と Supabase のセッションが消え、以後「未保存」表示になる（自動テスト）
- [ ] AC6：書き出しファイルに認証トークンやキーが含まれない（自動テスト）

### 設計方針
- 書き出しは Blob＋`<a download>`。ファイル名 `sonaelog-YYYYMMDD-HHmm.json`／`.csv`。
- CSV の列：保管場所、区分、カテゴリ、品名、数量、単位、期限、期限の精度、期限の種類、製造年月、製造から年数、計算した期限、期限の確認状況、期限の状態（書き出し時点の判定）、管理の状態、出どころ、要確認、1本あたりL、公称使用回数、メモ、セット内訳（`名前×数/単位` を `;` 区切り）、最終更新。
- ログアウトして消す：`signOut()`（オフラインでも localStorage のセッションは消す）→ Dexie の該当レコード削除 → 状態リセット。

### 検討した案と不採用の理由
| 案 | 採用 | 理由 |
|---|---|---|
| 書き出しをクラウドから取得して作る | 不採用 | オフラインでもバックアップを取りたい |
| File System Access API で保存先を選ぶ | 不採用 | Android Chrome で使えないことがある。ダウンロードで足りる |

### 検証方法
- 自動テスト：Vitest（JSON・CSV の生成）、Playwright（ダウンロード、ログアウト2種）。
