# 006 閲覧画面（ダッシュボード・在庫一覧・明細・保管場所）

- 状態：合意済み
- 依存：005

## 👤 ユーザーが確認するところ

### 何のための機能か
「何が・どこに・いくつあり・いつ期限か」をすぐ探せるようにします。ネットがあってもなくても、同じ画面・同じ操作で使えます。

### できるようになること
**画面の構成**（スマホでは画面下のタブで切り替え）
- ホーム（ダッシュボード）／在庫／保管場所／要確認／設定

**ホーム**
- 一番上に、オフラインで使えるかどうか（保存済み・最終同期日時／未保存）と、オンライン・オフライン・同期失敗の表示。
- 期限別の件数：期限切れ／3か月以内／1年以内／1年以内・日付未確認／期限未確認／問題なし報告・日付未記録／要確認。押すとその条件で在庫一覧が開く。
- 区分ごとの明細数：長期備蓄／非常持ち出し／ローリングストック／期限間近で取り出し済み。
- 水（リットル）：飲み水として数える分／そのうち期限未記録／生活用水候補。容量が分からない水の明細数。
- 食事（食数）と、食数に換算していない食品の明細数。
- 非常用トイレ（回数）と、回数未入力の明細数。
- 「明細 ○件」と書き、品物の個数とは区別する。

**在庫一覧・検索**
- 品名とメモをキーワードで検索（ひらがな・カタカナ、全角・半角、大文字・小文字の違いを区別しない）。
- 絞り込み：カテゴリ（食品・水・燃料・電源…）、保管場所、管理の状態（通常・買い替え予定・生活用水候補・優先消費待ち・試食検討・入れ替え判断保留）、期限の状態、要確認だけ。
- 並べ替え：期限が近い順（日付が分からないものは最後）／品名順／保管場所順／最近更新した順。
- 一覧には品名、数量と単位、保管場所、期限（計算した期限には「計算」の印）、期限の状態、管理の状態、要確認の印を出す。スマホではカード、パソコンでは表。
- 同じ品名で期限や保管場所が違うものは、別のカードとして並ぶ（まとめて1つにしない）。検索結果では同じ品名が隣り合うように並ぶ。
- 期限の状態は色だけでなく文字のラベルでも出す。

**明細**
- 品名、数量・単位、期限（「2027年8月」「2030年11月8日」「未確認」など記録どおり。製造年月から計算した期限は「（製造2024年5月から7年で計算）」を添える）と期限の種類、製造年月（記録があれば）、期限の状態、保管場所、管理の状態、メモ、要確認かどうか、情報の出どころ（本人の報告／写真からの仮登録／確認済み）、セット商品の中身（参考）、最終更新日時。
- 編集ボタン類（007）。オフラインのときは押せない。

**保管場所**
- 保管場所の一覧を区分ごとに表示。持ち出しリュックは4個それぞれ独立して表示。
- 各場所の名前、説明（階や棚など。未入力なら「未入力」）、入っている明細数、期限切れ・期限間近の件数。
- 場所を開くと、その場所の在庫一覧。
- 「期限間近で取り出し済み」は実際の置き場所が未確認であることを表示する（場所を断定しない）。

### 使い方の流れ
1. ホームで全体を確認し、気になる件数を押して一覧へ。
2. 在庫タブで品名を入れて検索（例：「単3」と入れると、単3電池がどこに何本あるか出る）。
3. 保管場所タブでリュックを開き、中身を確認する。

### やらないこと
- 写真の表示。
- 印刷用の一覧・PDF 出力。将来の拡張。
- 変更履歴の詳しい表示。将来の拡張。

### 設計方針
- 画面：`/`（ホーム）、`/items`（クエリ文字列で絞り込み状態を持つ。ダッシュボードからのリンクに使う）、`/items/:id`、`/locations`、`/locations/:id`、`/review`（007）、`/settings`（008）、`/login`。
- 検索の正規化：NFKC → カタカナをひらがなに → 小文字化。対象は name と notes。数百行なので毎回全件走査で十分。
- 状態管理：React Context＋useReducer（スナップショット、同期状態、認証状態）。外部の状態管理ライブラリは入れない。
- 一覧は 768px 以上で表、未満でカード。
- 日時表示は Asia/Tokyo 固定（`YYYY/MM/DD HH:mm`）。

### 検討した案と不採用の理由
| 案 | 採用 | 理由 |
|---|---|---|
| 全文検索ライブラリ（Fuse.js など） | 不採用 | あいまい検索は誤ヒットが増える。部分一致＋正規化で足りる |
| 名前でグループ化して1行に集約 | 不採用 | 勝手に結合しない（BRIEF 5.2）。並び順で隣接させる |

### 検証方法
- 自動テスト：Vitest（検索・並べ替え・絞り込み）、Playwright（画面、オフライン、幅 375px、axe）。
- 実データ：`data/checks/`（ローカル）。
